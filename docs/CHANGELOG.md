# v71 Search Robustness, Specialty Organization, Remaining Coverage Gaps

- **Fixed a real search bug** found through systematic query testing: the active search engine hard-rejects a resource unless it matches *every* detected intent (crisis/therapy/IOP-PHP/SUD/testing/ADHD/autism/youth/virtual/county, now also eating disorder/perinatal/LGBTQ+/older-adult/veteran/DV-SA/homelessness).
